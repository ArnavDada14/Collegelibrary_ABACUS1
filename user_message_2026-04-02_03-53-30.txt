═══════════════════════════════════════════
 1. INITIAL SETUP
═══════════════════════════════════════════

Initialize npm project. Install: express, mongoose, bcryptjs, jsonwebtoken, cors, dotenv, express-rate-limit.

Create .env:
  PORT=5000
  MONGO_URI=mongodb://localhost:27017/librarydb
  JWT_SECRET=mysecretkey123

═══════════════════════════════════════════
 2. MONGODB MODELS
═══════════════════════════════════════════

User.js — fields: name, email, password (bcrypt hashed), role (enum: 'admin'|'student'), studentId, createdAt

Book.js — fields: title, author, isbn (unique), category, totalCopies, availableCopies, description, coverImage (url string), addedAt

IssuedBook.js — fields:
  - userId (ref: User)
  - bookId (ref: Book)
  - issueDate (default: now)
  - dueDate (issueDate + 14 days auto-set)
  - returnDate (nullable)
  - status (enum: 'issued'|'returned'|'overdue', default: 'issued')
  - fineAmount (default: 0)
  Add virtual: auto-calculate fine at ₹2 per day after dueDate if not returned.

═══════════════════════════════════════════
 3. BACKEND — server.js
═══════════════════════════════════════════

- Connect to MongoDB via mongoose
- Use cors, express.json(), dotenv
- Apply express-rate-limit: 100 requests per 15 minutes
- Mount routes: /api/auth, /api/books, /api/issues
- Serve public/ folder as static files

═══════════════════════════════════════════
 4. AUTH ROUTES — server/routes/auth.js
═══════════════════════════════════════════

POST /api/auth/register
  - Accepts: name, email, password, studentId, role
  - Hash password with bcryptjs
  - Save to MongoDB, return JWT token

POST /api/auth/login
  - Validate credentials, return JWT + user info (id, name, role)

GET /api/auth/me (protected)
  - Return current user profile from JWT

middleware/auth.js — verify JWT, attach user to req.user. Add role check: requireAdmin middleware.

═══════════════════════════════════════════
 5. BOOKS ROUTES — server/routes/books.js
═══════════════════════════════════════════

GET /api/books
  - Support query filters: ?search= (title+author), ?category=, ?available=true, ?sort=title|author|newest

GET /api/books/:id — single book details

POST /api/books (admin only) — add new book

PUT /api/books/:id (admin only) — edit book

DELETE /api/books/:id (admin only) — delete book

═══════════════════════════════════════════
 6. ISSUE/RETURN ROUTES — server/routes/issues.js
═══════════════════════════════════════════

POST /api/issues — issue a book
  - Check availableCopies > 0, else return error
  - Decrement availableCopies by 1
  - Create IssuedBook record with dueDate = today + 14 days

GET /api/issues
  - Admin: all issued books (auto-update overdue status + fine on fetch)
  - Student: only their own issued books
  - Fine calculation: ₹2 per day overdue

PUT /api/issues/:id/return — return a book
  - Set returnDate = today
  - Calculate final fineAmount
  - Increment availableCopies by 1
  - Set status = 'returned'

GET /api/issues/overdue (admin only) — all overdue records with fines
